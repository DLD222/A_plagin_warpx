# A7.1 细化：原生核心接口与插件边界

> 本文件把 A7.1 拆成可验收的小步。  
> 约束：**不删除 WarpX**。WarpX 只从 Core 的实现中移出，继续作为 PicEm 的实现内核存在。

## 0. A7.1 的范围

A7.1 只做两件事：

```text
1. Core 只依赖抽象
2. 插件之间只通过 Core 主线耦合
```

A7.1 不做：

```text
删除 WarpX.H/.cpp
删除 WarpX 类
重写物理
```

删除 WarpX 属于 A7.9，必须在 A7.1–A7.8 全部验收后。
