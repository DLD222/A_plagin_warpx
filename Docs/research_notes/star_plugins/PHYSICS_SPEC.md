## 1. 牛顿引力求解器（插件一）

### 1.1 控制方程

∇²φ = 4πGρ                                        (1.1)

g = −∇φ                                            (1.2)

流体/粒子受到的加速度源项：S_mom = ρ g            (1.3)

**出处**：Binney & Tremaine, *Galactic Dynamics*, 2nd ed., §2.1（泊松方程与引力加速度）；
Kippenhahn, Weigert & Weiss, *Stellar Structure and Evolution*, 2nd ed., Ch. 2（恒星内部的
引力场）。

### 1.2 边界条件

- 开放（Dirichlet）：边界值取解析多极展开，最低阶为 φ = −GM_enc/r
- 周期：周期域上泊松方程无解，必须减去平均密度
  ∇²φ = 4πG(ρ − ρ̄)                                (1.4)
  即 Jeans swindle。**出处**：Binney & Tremaine §2.1 脚注；Kiessling (2003) 对 swindle 的讨论。

### 1.3 离散与求解

- 采用 AMReX MLMG 的 `computePhi`（七点/九点 Laplacian，与网格同阶）
- 收敛判据：残差 2-范数相对下降 1e-11，或绝对 1e-14

### 1.4 验收（解析解）

**参考实现**：`Tools/star/gravity_reference.py`（`--selftest` 自检通过）。解析式与本节表格
一一对应；自检用的是**独立恒等式**（Gauss 定律在表面、壳层定理、势在表面连续、外部势退化为
点质量），因此求解器与参考实现不会"一起错"。

| 用例 | 解析式 | 容差 | 状态 |
|---|---|---|---|
| 均匀球内部 | g(r) = (4/3)πGρr | RMS 相对误差 < 1e-3，逐点最大 < 5e-3 | ✅ ctest `gravity_uniform_sphere_3` |
| 均匀球外部 | g(r) = GM/r² | 同上 | ✅ 同上 |
| 点质量势 | φ = −GM/r，g = GM/r² | φ 与 g 的 RMS 相对误差 < 1e-3，g 逐点最大 < 5e-3 | ✅ ctest `gravity_point_mass_3` |
| 双同心球壳 | 分段解析（空腔 g=0、间隙 GM₁/r²、外部 G(M₁+M₂)/r²） | φ 的 RMS < 1e-3；g 的 RMS < 2e-3；空腔 max\|g\|/g_表面 < 2e-3 | ✅ ctest `gravity_two_shells_3` |
| 网格加密 | 误差随 dx 收敛 | 阶 ≥ 1.8（对 RMS 误差） | ✅ 三个算例各自给出 |

**容差的依据**（不是凑出来的，是二阶格式的下限）：
- 势 φ 由二阶离散 Poisson 方程给出，φ 的 RMS 相对误差按二阶收敛，1e-3 在 96³ 上有余量。
- 场 g = −∇φ 用二阶中心差分，其相对截断误差是 `(dx/r)²`（对 φ = −GM/r 可解析算出）。
  在 r 较小的比较带（如双球壳的间隙 r ≈ 0.19L），96³ 上 `(dx/r)² ≈ 3e-3`，
  因此 g 的判据按此放宽到 2e-3（RMS），并把 **收敛阶** 的要求放在 φ 上；
  均匀球外部与点质量的比较带离中心足够远，g 的 RMS 仍在 1e-3 以内。

## 2. 五阶矩流体（插件二）

### 2.1 守恒形式

∂U/∂t + ∇·F = S                                   (2.1)

U = (ρ_s, ρu, E)ᵀ                                  (2.2)
F = (ρ_s u, ρuu + p I, (E + p)u)ᵀ                  (2.3)
E = ½ρ|u|² + (3/2)p（单原子理想气体）               (2.4)
S = (反应源项, ρg, ρg·u + ε_react)                 (2.5)

多组分：每个组分 s 有自己的 ρ_s 方程，共享 u 与 p。

**出处**：Toro, *Riemann Solvers and Numerical Methods for Fluid Dynamics*, 3rd ed., Ch. 1–3
（守恒律与 Euler 方程）；LeVeque, *Finite Volume Methods for Hyperbolic Problems*, Ch. 2–6。

### 2.2 Riemann 求解器与重构

- HLLC 近似 Riemann 求解器（Toro 3rd ed., §10.4，波速估计 §10.5）
- 二阶精度：MUSCL-Hancock 预测-校正（Toro §6.4），限制器 minmod（Toro §13.3）
- CFL：0.3（可配置）

### 2.2b 离散格式（代码逐行对应这里的式子）

网格单元 $i$，界面 $i\pm 1/2$，$U_i^n$ 为守恒量的单元平均，$dx$ 为格距，$dt$ 由 (2.10) 给出。

**重构（minmod 限制）**

$$\Delta_i = \operatorname{minmod}(U_i - U_{i-1},\; U_{i+1} - U_i),\qquad
\operatorname{minmod}(a,b) = \tfrac12(\operatorname{sgn}a + \operatorname{sgn}b)\min(|a|,|b|) \tag{2.7a}$$

$$U_i^{+} = U_i + \tfrac12\Delta_i,\qquad U_i^{-} = U_i - \tfrac12\Delta_i \tag{2.7b}$$

**Hancock 半步预测**

$$\tilde U_i^{\pm} = U_i^{\pm} + \frac{dt}{2\,dx}\Big(F(U_i^{-}) - F(U_i^{+})\Big) \tag{2.8}$$

**界面通量（HLLC）**，左取 $L=i$ 的 $\tilde U^{+}$，右取 $R=i+1$ 的 $\tilde U^{-}$：

$$S_L = \min(u_L - c_L,\; u_R - c_R),\qquad S_R = \max(u_L + c_L,\; u_R + c_R) \tag{2.9a}$$

（Davis 波速估计；只用到 EOS 的声速，因此对任意 EOS 都成立。）

$$S_M = \frac{p_R - p_L + \rho_L u_L(S_L - u_L) - \rho_R u_R(S_R - u_R)}
{\rho_L(S_L - u_L) - \rho_R(S_R - u_R)} \tag{2.9b}$$

星状态（$K = L$ 或 $R$，总密度 $\rho$ 用于动量与能量；每个组分乘以同一因子）：

$$U^{*}_K = \rho_K\frac{S_K - u_K}{S_K - S_M}
\begin{pmatrix} 1 \\ S_M \\ v_{t,K} \\ \dfrac{E_K}{\rho_K} + (S_M - u_K)\Big(S_M + \dfrac{p_K}{\rho_K(S_K - u_K)}\Big) \end{pmatrix},
\qquad \rho_s^{*} = \rho_{s,K}\frac{S_K - u_K}{S_K - S_M} \tag{2.9c}$$

$$F_{i+1/2} =
\begin{cases}
F_L, & S_L \ge 0 \\
F_L + S_L(U^{*}_L - U_L), & S_M \ge 0 \\
F_R + S_R(U^{*}_R - U_R), & S_R \ge 0 \\
F_R, & \text{否则}
\end{cases} \tag{2.9d}$$

**更新与时间步**

$$U_i^{n+1} = U_i^{n} - \frac{dt}{dx}\big(F_{i+1/2} - F_{i-1/2}\big) \tag{2.10a}$$

$$dt = \mathrm{CFL}\cdot dx / \max_i\big(|u_i| + c_i\big),\qquad \mathrm{CFL} = 0.3 \ \text{（可配置）} \tag{2.10b}$$

**出处**：Toro 3rd ed. §6.4（MUSCL-Hancock，式 6.4.8–6.4.14）、§10.4（HLLC 通量）、§10.5（波速估计，
其中 Davis 估计见该节讨论）、§13.3（minmod 限制器）；Davis (1988) 的波速估计本身。

**实现约定**（与真实代码一一对应）：
- 状态的分量顺序是 `[rho_0 … rho_{ns-1}, mom_x, mom_y, mom_z, E]`（三维；维度由 AMREX_SPACEDIM 决定）。
- 步子只沿一个方向做（方向扫描），多方向用 Strang 分裂组合；本轮先做单方向扫描与 1D 验收。
- 重建在守恒量上做（Toro 的写法），压力由 EOS 从 $U$ 反解：$e = E - \tfrac12\rho|u|^2$。

### 2.3 物态方程（契约注入）

p = p(ρ, e, X_i)                                   (2.6)

- 契约：`IEquationOfState`，由插件注册；求解器不写死任何 EOS
- 实现顺序：理想气体（解析验收）→ 外部表插值（OPAL 类）
- **出处**：Kippenhahn et al. Ch. 14（EOS 在恒星结构中的角色）；Rogers & Nayfonov 2002 (OPAL) `[todo-src]` 表格格式与适用范围待核对

### 2.4 与引力的耦合

- 动量源项 ρg（式 1.3）
- 能量源项：g·(ρu)
- 引力能：E_grav = ½∫ρφ dV                        (2.7)
  **出处**：Binney & Tremaine §2.2

**离散做法（Strang 分裂）**：一个时间步内

1. 由当前密度解引力：∇²φ = 4πG(ρ − ρ̄)（周期）或 §1.2 的开放边界，取 **g** = −∇φ；
2. 半步"踢"：(ρu)* = (ρu)^n + (dt/2)ρ^n g^n， E* = E^n + (dt/2)(ρu)^n·g^n    (2.4a)
3. 流体单方向扫描推进 dt（式 2.10a）；
4. 由新密度再解一次引力，得 g^{n+1}，再做半步踢：                    (2.4b)
   (ρu)^{n+1} = (ρu)* + (dt/2)ρ^* g^{n+1}， E^{n+1} = E* + (dt/2)(ρu)^*·g^{n+1}

半步踢夹住守恒扫描，时间上二阶；源项本身用"()^n"的显式取值，因为 §2.4 的 ρg 不含 ρ 的梯度，
不引入新的稳定性限制（引力是长程力，其时间步限制由 §2.10b 的声速项覆盖）。

**Jeans 判据**：均匀介质 + 小扰动，线性色散关系为

  ω² = c_s² k² − 4πGρ                                     (2.4c)

不稳（ω²<0）的临界波数 k_J = √(4πGρ)/c_s，即 λ_J = 2π/k_J = c_s√(π/(Gρ))。
**出处**：Jeans (1902)；Binney & Tremaine §5.2.1（教科书表述）。

验收用两个波长把临界值夹住（比"直接测临界波长"更稳，不需要二分扫描）：
- λ = 2λ_J（m=1 模态）：测得的增长率与 σ = √(4πGρ − c_s²k²) 相差 < 5%；
- λ = λ_J/2（m=4 模态）：全程不增长（扰动幅度始终 ≤ 初始幅度的 1.5 倍）。

测幅方式：把密度投影到 cos(kx) 上，A(t) = (2/L)∫(ρ−ρ̄)cos(kx)dx，用增长段的 ln A 做斜率。

**静水平衡判据（2.4d）**：平面平行、自引力的等温薄层有解析平衡态。设 ρ = ρ₀ sech²(x/z₀)、
p = ρ c_s²、u = 0，代人

  dp/dx = −ρ dφ/dx,      d²φ/dx² = 4πGρ

（式 1.1 与动量方程的静平衡）得到**唯一**的尺度

  z₀² = c_s²/(2πGρ₀)                                        (2.4d)

与势 φ = 2c_s² ln cosh(x/z₀)、场 g = −(2c_s²/z₀) tanh(x/z₀)。
**出处**：Spitzer (1942) 的等温薄层解；教科书讨论见 Binney & Tremaine §5.2（自引力薄层）。
核验：d²φ/dx² = (2c_s²/z₀²) sech²(x/z₀) = 4πGρ ✓（用 2.4d）。

验收方式：盒子取 ±6z₀（边缘密度只剩 2.4e-5 ρ₀，透射边界不会扰动内部），初始条件就是精确解，
跑 3 个动力学时间 t_dyn = z₀/c_s，要求
- 密度的相对 L1 变化 < 1e-2，最大逐点相对偏差 < 3e-2；
- 速度始终 < 1e-2 c_s（平衡态不应被激发）。
这个算例与 Jeans 是同一个耦合的两个相反极限：那里引力赢、这里压力与引力恰好打平。

**实测与两点实现经验**（记在 §6 里，避免下次再踩）：

- 边界鬼格必须喂**精确平衡态**，不能用零梯度透射。边缘 ρ/ρ₀ ≈ 5e-5，那里 (1/ρ)dρ/dx = 2 tanh(x/z₀)/z₀
  并不小，零梯度外推使边界面的压力偏大 O((dx/z₀)p)；相对于当地密度这相当于约 10 倍 g 的加速度，
  稀薄气体随即内落、并在 3 t_dyn 内穿过整个被测区域（实测外区速度可达 5 c_s）。
- 指标只统计 |x| ≤ 2z₀（ρ ≥ 0.07ρ₀）的区域，并在测试注释里写明理由；外区密度低到 3e-4ρ₀，
  任何逐点相对误差都没有物理意义。
- 残余运动是"压力梯度"与"引力踢"两套离散的 O(dx²) 失配在 3 个穿越时间上的积分，实测随分辨率下降
  （2.6e-2 → 1.1e-2 c_s），因此判据给到几个百分点而不是零。

这两条一起才是完整的证据：格式二阶，且在间断上不产生振荡、不移动激波位置。

### 3.3b 能量产生率

ε_nuc [erg g⁻¹ s⁻¹] = (1/ρ) Σ_i Q_i [MeV] · (1.602176634e-6 erg/MeV) · r_i   (3.4)

其中 `r_i` 为该反应单位体积的反应率（mol cm⁻³ s⁻¹）。中微子带走的能量单独累加为 ε_ν，
**不进能量方程**，只用于与光度/中微子通量对账。`[spec]`

### 3.4 能量与中微子分开记录

ε_nuc = ε_pp + ε_CNO（局部沉积）
ε_ν   = ε_pp,ν + ε_CNO,ν（逃逸；只从能量方程中扣除，不进流体）

这样光度积分可与中微子损失分别对账。`[spec]`

## 6. 与既有实现的集成细节（实测记录）

写 `NewtonGravitySolver` 时撞到的两个约束，记下来避免重复踩：

1. **ablastr 的 `computePhi` 要求 β 的各分量 < 1**（断言在 `PoissonSolver.H`）。
   它自己承担 4π 因子，所以本插件取 **β = 1/(4π)**、右端 `G(ρ − ⟨ρ⟩)`，
   于是 `∇·(β∇φ) = G(ρ−⟨ρ⟩)` 等价于 `∇²φ = 4πG(ρ−⟨ρ⟩)`。
2. **不传 `boundary_handler` 时，ablastr 默认把域边界设为 Dirichlet**（`PoissonSolver.H:396-403`）。
   周期盒子因此触发 AMReX 的断言（要求 LinOp 全周期）。正确接法是提供一个带
   `lobc`/`hibc` 的 handler，全维填 `LinOpBCType::Periodic`。
3. **`open` 边界只对非周期方向取 Dirichlet**：AMReX 断言算符边界类型要与 Geometry 的周期性一致
   （`MLLinOp.H:1775`），所以周期性平面（如等温薄层的横向）必须保持 `Periodic`，
   否则求解直接 abort。`solvePotential` 里现在按 `geom.isPeriodic(d)` 逐方向判断。
4. **Dirichlet 边界数据位于"面"上，不是网格中心**（实测）。`MLMGBndry::setBoxBC` 对物理边界
   把数据位置偏移硬编码为 0，`setPhysBndryValues` 只是把 `phi` 的鬼格值搬进边界数组，
   所以调用方必须把鬼格值填成**该面处**的势（法向坐标夹到域边界，切向取网格中心），
   算符再用 `2φ_face − φ_内` 外推。若填成鬼格中心的值，等价于把边界平移半格，
   实测误差立刻变成一阶（球算例 5%、收敛阶 1.0）。`setDomainBCLoc` 在这条路径上没有
   改变结果，因此实现里干脆不用它，只依赖默认的"面"约定。
5. **体积分数必须从格子下角起算**。子采样写成 `x + (a+0.5)h`（漏掉 `−dx/2`）会让
   数字化后的球整体偏移半格，产生一个偶极矩；质量仍然守恒（差值 1e-5），但外部场错 2%~7%，
   而且表现为一阶收敛。这个 bug 在球算例上曾伪装成"边界条件错"，查了三轮才对上账：
   把子采样改回 `x − dx/2 + (a+0.5)h` 后，直接求和与解析解立刻回到 1e-5 量级。
