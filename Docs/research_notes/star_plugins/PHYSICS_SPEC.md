## 1. 牛顿引力求解器（插件一）

### 1.1 控制方程

∇²φ = 4πGρ                                        (1.1)

g = −∇φ                                            (1.2)

流体/粒子受到的加速度源项：S_mom = ρ g            (1.3)

**出处**：Binney & Tremaine, *Galactic Dynamics*, 2nd ed., §2.1（泊松方程与引力加速度）；
Kippenhahn, Weigert & Weiss, *Stellar Structure and Evolution*, 2nd ed., Ch. 2（恒星内部的
引力场）。

### 1.2 边界条件

- 开放（Dirichlet）：边界值取解析多极展开，最低阶为 φ = −GM_enc/r
- 周期：周期域上泊松方程无解，必须减去平均密度
  ∇²φ = 4πG(ρ − ρ̄)                                (1.4)
  即 Jeans swindle。**出处**：Binney & Tremaine §2.1 脚注；Kiessling (2003) 对 swindle 的讨论。

### 1.3 离散与求解

- 采用 AMReX MLMG 的 `computePhi`（七点/九点 Laplacian，与网格同阶）
- 收敛判据：残差 2-范数相对下降 1e-11，或绝对 1e-14

### 1.4 验收（解析解）

**参考实现**：`Tools/star/gravity_reference.py`（`--selftest` 自检通过）。解析式与本节表格
一一对应；自检用的是**独立恒等式**（Gauss 定律在表面、壳层定理、势在表面连续、外部势退化为
点质量），因此求解器与参考实现不会"一起错"。

| 用例 | 解析式 | 容差 | 状态 |
|---|---|---|---|
| 均匀球内部 | g(r) = (4/3)πGρr | RMS 相对误差 < 1e-3，逐点最大 < 5e-3 | ✅ ctest `gravity_uniform_sphere_3` |
| 均匀球外部 | g(r) = GM/r² | 同上 | ✅ 同上 |
| 点质量势 | φ = −GM/r，g = GM/r² | φ 与 g 的 RMS 相对误差 < 1e-3，g 逐点最大 < 5e-3 | ✅ ctest `gravity_point_mass_3` |
| 双同心球壳 | 分段解析（空腔 g=0、间隙 GM₁/r²、外部 G(M₁+M₂)/r²） | φ 的 RMS < 1e-3；g 的 RMS < 2e-3；空腔 max\|g\|/g_表面 < 2e-3 | ✅ ctest `gravity_two_shells_3` |
| 网格加密 | 误差随 dx 收敛 | 阶 ≥ 1.8（对 RMS 误差） | ✅ 三个算例各自给出 |

**容差的依据**（不是凑出来的，是二阶格式的下限）：
- 势 φ 由二阶离散 Poisson 方程给出，φ 的 RMS 相对误差按二阶收敛，1e-3 在 96³ 上有余量。
- 场 g = −∇φ 用二阶中心差分，其相对截断误差是 `(dx/r)²`（对 φ = −GM/r 可解析算出）。
  在 r 较小的比较带（如双球壳的间隙 r ≈ 0.19L），96³ 上 `(dx/r)² ≈ 3e-3`，
  因此 g 的判据按此放宽到 2e-3（RMS），并把 **收敛阶** 的要求放在 φ 上；
  均匀球外部与点质量的比较带离中心足够远，g 的 RMS 仍在 1e-3 以内。

## 2. 五阶矩流体（插件二）

### 2.1 守恒形式

∂U/∂t + ∇·F = S                                   (2.1)

U = (ρ_s, ρu, E)ᵀ                                  (2.2)
F = (ρ_s u, ρuu + p I, (E + p)u)ᵀ                  (2.3)
E = ½ρ|u|² + (3/2)p（单原子理想气体）               (2.4)
S = (反应源项, ρg, ρg·u + ε_react)                 (2.5)

多组分：每个组分 s 有自己的 ρ_s 方程，共享 u 与 p。

**出处**：Toro, *Riemann Solvers and Numerical Methods for Fluid Dynamics*, 3rd ed., Ch. 1–3
（守恒律与 Euler 方程）；LeVeque, *Finite Volume Methods for Hyperbolic Problems*, Ch. 2–6。

### 2.2 Riemann 求解器与重构

- HLLC 近似 Riemann 求解器（Toro 3rd ed., §10.4，波速估计 §10.5）
- 二阶精度：MUSCL-Hancock 预测-校正（Toro §6.4），限制器 minmod（Toro §13.3）
- CFL：0.3（可配置）

### 2.2b 离散格式（代码逐行对应这里的式子）

网格单元 $i$，界面 $i\pm 1/2$，$U_i^n$ 为守恒量的单元平均，$dx$ 为格距，$dt$ 由 (2.10) 给出。

**重构（minmod 限制）**

$$\Delta_i = \operatorname{minmod}(U_i - U_{i-1},\; U_{i+1} - U_i),\qquad
\operatorname{minmod}(a,b) = \tfrac12(\operatorname{sgn}a + \operatorname{sgn}b)\min(|a|,|b|) \tag{2.7a}$$

$$U_i^{+} = U_i + \tfrac12\Delta_i,\qquad U_i^{-} = U_i - \tfrac12\Delta_i \tag{2.7b}$$

**Hancock 半步预测**

$$\tilde U_i^{\pm} = U_i^{\pm} + \frac{dt}{2\,dx}\Big(F(U_i^{-}) - F(U_i^{+})\Big) \tag{2.8}$$

**界面通量（HLLC）**，左取 $L=i$ 的 $\tilde U^{+}$，右取 $R=i+1$ 的 $\tilde U^{-}$：

$$S_L = \min(u_L - c_L,\; u_R - c_R),\qquad S_R = \max(u_L + c_L,\; u_R + c_R) \tag{2.9a}$$

（Davis 波速估计；只用到 EOS 的声速，因此对任意 EOS 都成立。）

$$S_M = \frac{p_R - p_L + \rho_L u_L(S_L - u_L) - \rho_R u_R(S_R - u_R)}
{\rho_L(S_L - u_L) - \rho_R(S_R - u_R)} \tag{2.9b}$$

星状态（$K = L$ 或 $R$，总密度 $\rho$ 用于动量与能量；每个组分乘以同一因子）：

$$U^{*}_K = \rho_K\frac{S_K - u_K}{S_K - S_M}
\begin{pmatrix} 1 \\ S_M \\ v_{t,K} \\ \dfrac{E_K}{\rho_K} + (S_M - u_K)\Big(S_M + \dfrac{p_K}{\rho_K(S_K - u_K)}\Big) \end{pmatrix},
\qquad \rho_s^{*} = \rho_{s,K}\frac{S_K - u_K}{S_K - S_M} \tag{2.9c}$$

$$F_{i+1/2} =
\begin{cases}
F_L, & S_L \ge 0 \\
F_L + S_L(U^{*}_L - U_L), & S_M \ge 0 \\
F_R + S_R(U^{*}_R - U_R), & S_R \ge 0 \\
F_R, & \text{否则}
\end{cases} \tag{2.9d}$$

**更新与时间步**

$$U_i^{n+1} = U_i^{n} - \frac{dt}{dx}\big(F_{i+1/2} - F_{i-1/2}\big) \tag{2.10a}$$

$$dt = \mathrm{CFL}\cdot dx / \max_i\big(|u_i| + c_i\big),\qquad \mathrm{CFL} = 0.3 \ \text{（可配置）} \tag{2.10b}$$

**出处**：Toro 3rd ed. §6.4（MUSCL-Hancock，式 6.4.8–6.4.14）、§10.4（HLLC 通量）、§10.5（波速估计，
其中 Davis 估计见该节讨论）、§13.3（minmod 限制器）；Davis (1988) 的波速估计本身。

**实现约定**（与真实代码一一对应）：
- 状态的分量顺序是 `[rho_0 … rho_{ns-1}, mom_x, mom_y, mom_z, E]`（三维；维度由 AMREX_SPACEDIM 决定）。
- 步子只沿一个方向做（方向扫描），多方向用 Strang 分裂组合；本轮先做单方向扫描与 1D 验收。
- 重建在守恒量上做（Toro 的写法），压力由 EOS 从 $U$ 反解：$e = E - \tfrac12\rho|u|^2$。

### 2.3 物态方程（契约注入）

p = p(ρ, e, X_i)                                   (2.6)

- 契约：`IEquationOfState`，由插件注册；求解器不写死任何 EOS
- 实现顺序：理想气体（解析验收）→ 外部表插值（OPAL 类）
- **出处**：Kippenhahn et al. Ch. 14（EOS 在恒星结构中的角色）；Rogers & Nayfonov 2002 (OPAL) `[todo-src]` 表格格式与适用范围待核对

**不透明度的可解析近似**（已实现，`Tools/star/ssm_compare.py` 的 `kappa_analytic`）：

  κ_bf = 4.32e22 Z(1+X) ρ / T^3.5     （Kramers 束缚-自由）
  κ_ff = 3.68e19 (1−Z)(1+X) ρ / T^3.5 （Kramers 自由-自由）
  κ_es = 0.2 (1+X)                     （电子散射）

**出处**：<https://www.ita.uni-heidelberg.de/research/klessen/people/klessen/lectures/2012-A/Stars/Klessen-Stellar-Astrophysics.pdf>（opacity 一节，式与常数照抄）。
H⁻ 项（低温包层的主导项）**故意没实现**：抓取的原文里指数被解析成 `T^9`，量纲上不可能，未敢凭猜测填；
它只在 T ≲ 10⁴ K 的外层重要，而这一层的对照本来就是"解析式不够用"的证据。

**实测结论（见 §4.2b）**：该近似在太阳中心比 OPAL 低 **4.4 倍**、在 H⁻ 包层低 2–3 个量级。原因是金属真实的
束缚-自由截面远大于 Kramers 的 Z 标度，而包层完全由 H⁻ 与电离区的束缚-自由主导。**因此结构模型必须用表，
解析式只用于说明差距在哪里。**

### 2.4 与引力的耦合

- 动量源项 ρg（式 1.3）
- 能量源项：g·(ρu)
- 引力能：E_grav = ½∫ρφ dV                        (2.7)
  **出处**：Binney & Tremaine §2.2

**离散做法（Strang 分裂）**：一个时间步内

1. 由当前密度解引力：∇²φ = 4πG(ρ − ρ̄)（周期）或 §1.2 的开放边界，取 **g** = −∇φ；
2. 半步"踢"：(ρu)* = (ρu)^n + (dt/2)ρ^n g^n， E* = E^n + (dt/2)(ρu)^n·g^n    (2.4a)
3. 流体单方向扫描推进 dt（式 2.10a）；
4. 由新密度再解一次引力，得 g^{n+1}，再做半步踢：                    (2.4b)
   (ρu)^{n+1} = (ρu)* + (dt/2)ρ^* g^{n+1}， E^{n+1} = E* + (dt/2)(ρu)^*·g^{n+1}

半步踢夹住守恒扫描，时间上二阶；源项本身用"()^n"的显式取值，因为 §2.4 的 ρg 不含 ρ 的梯度，
不引入新的稳定性限制（引力是长程力，其时间步限制由 §2.10b 的声速项覆盖）。

**Jeans 判据**：均匀介质 + 小扰动，线性色散关系为

  ω² = c_s² k² − 4πGρ                                     (2.4c)

不稳（ω²<0）的临界波数 k_J = √(4πGρ)/c_s，即 λ_J = 2π/k_J = c_s√(π/(Gρ))。
**出处**：Jeans (1902)；Binney & Tremaine §5.2.1（教科书表述）。

验收用两个波长把临界值夹住（比"直接测临界波长"更稳，不需要二分扫描）：
- λ = 2λ_J（m=1 模态）：测得的增长率与 σ = √(4πGρ − c_s²k²) 相差 < 5%；
- λ = λ_J/2（m=4 模态）：全程不增长（扰动幅度始终 ≤ 初始幅度的 1.5 倍）。

测幅方式：把密度投影到 cos(kx) 上，A(t) = (2/L)∫(ρ−ρ̄)cos(kx)dx，用增长段的 ln A 做斜率。

**静水平衡判据（2.4d）**：平面平行、自引力的等温薄层有解析平衡态。设 ρ = ρ₀ sech²(x/z₀)、
p = ρ c_s²、u = 0，代人

  dp/dx = −ρ dφ/dx,      d²φ/dx² = 4πGρ

（式 1.1 与动量方程的静平衡）得到**唯一**的尺度

  z₀² = c_s²/(2πGρ₀)                                        (2.4d)

与势 φ = 2c_s² ln cosh(x/z₀)、场 g = −(2c_s²/z₀) tanh(x/z₀)。
**出处**：Spitzer (1942) 的等温薄层解；教科书讨论见 Binney & Tremaine §5.2（自引力薄层）。
核验：d²φ/dx² = (2c_s²/z₀²) sech²(x/z₀) = 4πGρ ✓（用 2.4d）。

验收方式：盒子取 ±6z₀（边缘密度只剩 2.4e-5 ρ₀，透射边界不会扰动内部），初始条件就是精确解，
跑 3 个动力学时间 t_dyn = z₀/c_s，要求
- 密度的相对 L1 变化 < 1e-2，最大逐点相对偏差 < 3e-2；
- 速度始终 < 1e-2 c_s（平衡态不应被激发）。
这个算例与 Jeans 是同一个耦合的两个相反极限：那里引力赢、这里压力与引力恰好打平。

**实测与两点实现经验**（记在 §6 里，避免下次再踩）：

- 边界鬼格必须喂**精确平衡态**，不能用零梯度透射。边缘 ρ/ρ₀ ≈ 5e-5，那里 (1/ρ)dρ/dx = 2 tanh(x/z₀)/z₀
  并不小，零梯度外推使边界面的压力偏大 O((dx/z₀)p)；相对于当地密度这相当于约 10 倍 g 的加速度，
  稀薄气体随即内落、并在 3 t_dyn 内穿过整个被测区域（实测外区速度可达 5 c_s）。
- 指标只统计 |x| ≤ 2z₀（ρ ≥ 0.07ρ₀）的区域，并在测试注释里写明理由；外区密度低到 3e-4ρ₀，
  任何逐点相对误差都没有物理意义。
- 残余运动是"压力梯度"与"引力踢"两套离散的 O(dx²) 失配在 3 个穿越时间上的积分，实测随分辨率下降
  （2.6e-2 → 1.1e-2 c_s），因此判据给到几个百分点而不是零。

### 3.3b 能量产生率

ε_nuc [erg g⁻¹ s⁻¹] = (1/ρ) Σ_i Q_i [MeV] · (1.602176634e-6 erg/MeV) · r_i   (3.4)

其中 `r_i` 为该反应单位体积的反应率（mol cm⁻³ s⁻¹）。中微子带走的能量单独累加为 ε_ν，
**不进能量方程**，只用于与光度/中微子通量对账。`[spec]`

### 3.3c 反应网络（已实现）

**组分与反应**（`Source/Plugins/FluidMoments/SolarNetwork.H`）：9 个组分
`p, d, he3, he4, be7, c12, c13, n14, n15`，9 个反应：pp-I 链（CF88 #2, #4, #18）、
**pp-II 分支**（#24 ³He(α,γ)⁷Be + ⁷Be 电子俘获 #41，后者与极快的 ⁷Li(p,α)⁴He 归并为
⁷Be + p → 2⁴He，Q = 0.862 + 17.34695）、CNO 主循环（#61, #64, #71, #78）。
两个 β 衰变（¹³N→¹³C、¹⁵O→¹⁵N）折进 #61 与 #71：寿命是分钟量级，对应核反应时标是年，
有效速率取慢的那一步。每个反应的质量数都平衡（1+1=2、2+1=3、3+3=4+1+1、12+1=13、…），
测试把这条当作化学计量式的自检。

**电子俘获的速率律**（#41）：λ = ρ Y_e f41（f41 已是 cm³/mol/s，阿伏伽德罗因子相消），
并受原文上限 λ ≤ 1.51e-7 s⁻¹ 约束；反应率 r = λ n(⁷Be)。pp-I 与 pp-II 可用
`advance(..., include_pp2)` 开关切换，这样纯 pp-I 的解析解仍然可测。

**速率律**（与 §3.3 一致）：两体反应 r = n_a n_b f_screen ⟨σv⟩/(1+δ_ab)，⟨σv⟩ = f/N_A，n = ρ_cgs X/(A m_u)。

**电子屏蔽**（Salpeter 1954 弱屏蔽，已实现）：f_screen = exp(Λ)，
Λ = Z₁Z₂ e²/(R_D k T)，Debye 半径 1/R_D² = 4π e²/(k T)(n_e + Σ_i n_i Z_i²)，Gaussian cgs。
**出处**：Salpeter (1954)；本实现采用的 cgs 形式见
<https://public.lanl.gov/friedland/info05/INFO05talks/GruzinovINFO05.pdf>（式 2–3）与
<https://ucolick.org/~woosley/ay220-15/lectures/lecture5.15.pdf>（同式，并给出弱屏蔽条件 R_D ≫ n_Z^{-1/3}）。
太阳中心 Λ ≈ 0.05（弱屏蔽），增强约 5%。
本网络只用"速率律无歧义"的 7 条；#41（⁷Be 电子俘获）与 #42（⁷Be(p,γ)⁸B）属于 pp-II/III 分支，
需要依赖电子密度的速率律与中微子能量，标 `[todo-src]`。

**积分**：网络是刚性的——pp 链里 D 与 ³He 的准平衡时标 ~1e-4 s，而质子燃烧 ~1e17 s（比 ~1e21）。
显式欧拉会立刻发散（实测：一步就从正密度冲到 NaN），因此 `advance` 用**后向欧拉 + 牛顿迭代**
（数值 Jacobi 矩阵 8×8、带正性阻尼的高斯消元）。时间上一阶，对本项目够用（反应与流体时标相差极大），
且对这种网络形式保持所有密度为正。

**验收**：ctest `fluid_network_3`
- 纯氢、太阳中心条件（T9 = 0.015634、ρ = 152.699 g/cm³，取自 SSM 剖面文件）：烧掉 59.5% 质子后，
  质子丰度与 pp-I 准平衡解析式 n_p(t) = n_p0/(1+n_p0⟨σv⟩t) 相差 **5.4e-4**；
- 同一个演化里"每个 ⁴He 沉积的能量" = **26.732 MeV**（= 2×1.442 + 2×5.494 + 12.860），与 Q 值之和
  相差 7e-6（来自准平衡偏离，非记账错误）；
- CNO 算例：C+N 的**核数目**守恒到机器精度（1e-16 量级），每产一个 ⁴He 消耗 4.005 个质子
  （稳态应为 4，多出的 0.5% 是中间核——¹³C 多存 1 个质子、¹⁴N 多存 2 个——未满时的存量），
  且稳态下 ¹⁴N 主导（其质子俘获是最慢的一步）；
- **pp-II 分支**（太阳成分 X = 0.34、Y = 0.64）：⁷Be 只是痕量（峰值 2.4e-6 kg/m³），

### 3.3d 与流体状态的耦合（已实现）

`applySolarNetwork(state, dt, gamma, layout, &neutrino_energy)`（`FluidMoments.cpp`）按算子分裂接在流体扫描之后：

1. 每个格子由状态读出总密度 ρ 与压力 p = (γ−1)(E − ½ρ|u|²)；
2. **温度由组分给出**：完全电离气体的平均分子量 1/μ = Σ_s X_s(1+Z_s)/A_s（Kippenhahn et al. §3），
   于是 T = p μ m_u/(ρ k_B)，T9 = T/10⁹；纯氢 μ = 0.5，太阳混合 (X=0.70, Y=0.28, Z=0.02) μ = 0.6167；
3. 调用 §3.3c 的刚性求解器推进全部组分密度；
4. **只把沉积能量加进 E**（J/m³），中微子能量通过可选输出缓冲返回给调用方，不进气体。

时间上一阶（算子分裂），对本项目够用：反应时标比流体时标高若干量级。

验收 ctest `fluid_network_coupling_3`：
- μ：纯氢 0.5000、太阳混合 0.6167 ✓（教科书值）；
- **惰性盒子**（纯 ⁴He，本网络无反应可走）：能量漂移 **0.0**，组分不动 ✓；
- **燃烧盒子**（X_p=0.35、Y=0.63、C+N=0.02、T9=0.2）：流体能量增量与网络报告的沉积能量之比
  **1.000000000**；返回给调用方的中微子能量与网络值一致；耦合后的组分与"单独跑网络"的结果
  逐组分相同（最大相对差 **0.0**）——说明耦合既没多算能量也没改组分。

这一节踩过的两个坑记在这里：单步耗时必须短到让能量增量相对内能可分辨（否则 E + ΔE 在双精度下
加不进去），且构型里必须真能烧（T9 = 0.001 时网络几乎冻结，比值检查会退化成 0/0）。

## 4.3 恒星结构求解器（第一步：静力学 + Lane-Emden 验证）

太阳模型需要结构方程，而不是流体扫描。第一步做**静力学部分**，在质量坐标下积分

  dr/dm = 1/(4πr²ρ),      dP/dm = −Gm/(4πr⁴)                     (4.5)

配多方物态 P = Kρ^{1+1/n}。它的解**独立已知**：Lane-Emden 方程

  θ'' + (2/ξ)θ' + θ^n = 0,  θ(0)=1, θ'(0)=0                     (4.6)

的零点 ξ₁ 给出恒星表面。两套表述（无量纲半径 vs 带 4πG 的质量坐标）互相独立，
所以它们的一致性能抓住单一实现会掩盖的公式错误——与"两份 CF88 转写互校"是同一个思路。

映射（Kippenhahn et al. ch.19；Chandrasekhar, *Introduction to the Study of Stellar Structure* ch.IV）：

  r = αξ, ρ = ρ_cθ^n, R = αξ₁, M = 4πα³ρ_c(−ξ₁²θ'(ξ₁)), α² = (n+1)Kρ_c^{1/n−1}/(4πG)  (4.7)

于是 (M, R, n) 定死 ρ_c 与 K，质量坐标的积分**没有自由参数**。

**验收**：ctest `fluid_lane_emden`（`Tools/star/stellar_structure.py --selftest`）
- ξ₁ = 3.653754 / 6.896849（参考值 3.65375 / 6.89685），θ'(ξ₁) = −0.203301 / −0.042430（参考 −0.20330 / −0.04243）；
- 质量坐标积分与 Lane-Emden 剖面逐点比较：r(m) 最大相对差 **2.9e-4**，ρ(m) **1.5e-8**（n=1.5）与 **3.0e-9**（n=3）。

**两个实现细节**（都是踩过的）：中心是 dr/dm 的坐标奇点，必须用解析展开起步
（r = (3m/(4πρ_c))^{1/3}）并按"当前质量的 2%"分级步进——任何固定步长下限都会让第一步跨过整个内区，
起动的瞬态再向外传播（实测：1e-6 M 的步长下限在 m=1e-4 M 处造成 13% 的 r 误差）。
比较时排除最内一层，因为 Lane-Emden 参考表本身在 ξ < 3e-3 处过粗，线性插值 r ~ m^{1/3} 会把参考表的
粗糙当成积分的误差（这一条也写进了代码注释）。

### 4.3b 四方程积分与"从 SSM 中心出发"的诊断

结构方程的完整形式（质量坐标）：

  dr/dm = 1/(4πr²ρ),  dP/dm = −Gm/(4πr⁴),  dT/dm = (T/P)∇ dP/dm,  dL/dm = ε_nuc − ε_ν   (4.8)

其中 ∇ = min(∇_rad, ∇_ad)，∇_rad = 3κLP/(16πacGmT⁴)，本轮取 ∇_ad = 0.4（单原子理想气体；
对流按"绝热极限"处理，不引入 α_MLT）。EOS 为理想气体 + 辐射：P = ρkT/(μm_u) + aT⁴/3。

**做法**：不是另造一颗星，而是**从 SSM 自己的中心 (P_c, T_c) 与组分剖面出发**，用**我们自己的**
EOS、不透明度与反应网络向前积分，问"我们的物理能在真实太阳结构上走多远"。这是对物理模块最直接的诊断。

**结果**（`stellar_structure.py --diagnostic`，两行分别用解析 κ 与 OPAL κ）：

| m/M | r/R 解析κ | r/R OPAL | r/R SSM | T 解析κ | T OPAL | T SSM |
|---|---|---|---|---|---|---|
| 0.009 | 0.045 | 0.045 | 0.006 | 1.55e7 | 1.50e7 | 1.52e7 |
| 0.19 | 0.157 | 0.151 | 0.197 | 1.49e7 | **1.15e7** | 1.11e7 |
| 0.88 | 0.390 | 0.455 | 0.863 | 1.45e7 | 8.9e6 | 4.3e6 |

表面：解析 κ 给 **R = 0.43 R☉、L = 3.4 L☉**；换成 OPAL 后 **R = 0.54 R☉、L = 1.13 L☉**（太阳 1.000、1.000）。

**结论**：
- 用 OPAL 后**深内部与 SSM 吻合到百分之几**（m/M ≤ 0.2：T 差 4%、ρ 差 2%），**光度落在太阳的 13% 以内**——
  这验证了我们的 EOS + 网络 + κ 查表 + 结构积分这一整套；
- 剩余偏差集中在**包层**：对流按绝热极限（无混合长），EOS 无氢氦电离，因此外层过熱过密、半径偏小。
  这两条是 §4.3c 的待办，而不是靠调参能修的。

**过程中修掉的两个实现错误**（都记在这里以防重犯）：
- 辐射常数写成 7.57e-15 而非 a = 4σ/c = **7.57e-16** J m⁻³K⁻⁴，使 ∇_rad 整体偏小 10 倍；
- SSM 剖面最内一层在 m/M = 0.0097 而不在 0，插值时 m 小于该值会返回**表面**组分（μ=0.60 而非 0.85）。

### 4.3c 混合长对流（MLT，已实现）

包层是对流区，绝热极限（∇ = ∇_ad）丢掉了超绝热层与混合长参数。按 Weiss 讲义
（<https://theory.tifr.res.in/~jigsaw/weiss.pdf>，§"mixing length"）实现：

  F_conv = ρ c_P T √g · l²/(4√2) · H_P^{−3/2} · (∇ − ∇_ad)^{3/2},   l = α_MLT H_P,  H_P = P/(ρg)   (4.9)

辐射通量与 ∇_rad 的定义（F = A_r ∇_rad）联立后，对 x = ∇ − ∇_ad 得到单调方程

  A_c x^{3/2} + A_r x = A_r (∇_rad − ∇_ad),   A_r = 4acT⁴g/(3κP)   (4.10)

二分求解即可：x=0 是纯辐射解，x→Δ 是高效对流（绝热）极限。

**验收**（ctest `fluid_lane_emden` 内）：
- α_MLT → 0 时 ∇ → ∇_rad（实测比值误差 1.4e-3）；
- α_MLT 很大时 ∇ → ∇_ad（误差 < 2%·Δ）；
- 任意 α_MLT 下 F_rad + F_conv = L/(4πr²)，相对误差 < 1e-6。

**过程中修的系数错误**：A_r 一度写成 4acT⁴g/(3κP) 的 4 倍（用了 16acT⁴g/(3κP)），使 ∇_rad 整体偏大 4 倍。
抓住它的是与 SSM 自己剖面的 ∇ = dlnT/dlnP 逐点比：用 3κLP/(16πacGmT⁴) 时实测 0.2115 vs SSM 0.2130（差 0.7%），
用 4 倍系数则完全不匹配。

**结论：α_MLT = 1.5 时 MLT 与绝热极限给出相同结果**（∇ ≈ ∇_ad），结构诊断的数字不变
（R = 0.539 R☉、L = 1.125 L☉）。也就是说**包层的剩余偏差不是对流效率造成的，而是 EOS 缺电离项**
——这正是下一步。

### 4.3d 电离 EOS（已实现）

`Tools/star/eos.py`（ctest `fluid_saha_eos`）：H、H⁺、He、He⁺、He⁺⁺ 的 Saha 平衡，

  n_{i+1} n_e / n_i = 2 (2π m_e k T/h²)^{3/2} (U_{i+1}/U_i) exp(−χ_i/kT)                     (4.11)

χ_H = 13.5984 eV、χ_HeI = 24.5874 eV、χ_HeII = 54.4178 eV（NIST 原子光谱数据库），
配分函数取基态（U=1），金属按 Z=7、A=14 全电离。电子密度由电中性条件二分求出；
压力含辐射项；内能含各离子的电离能，于是 **∇_ad 可由第一定律 du + P d(1/ρ) = 0 直接数值求出**，
不需要配分函数的导数。

**关键的物理：压力电离（连续谱下移）**。裸 Saha 方程即使把 Debye-Hückel 下移放进指数，
在太阳中心仍留下约 15% 的中性氢——因为 kT ≈ 1.3 keV 使 Boltzmann 因子对 χ 几乎不敏感。
采用标准的 Debye-Hückel 判据：当 χ_eff = χ − (Z+1)e²/R_D ≤ 0 时该能级被压入连续谱，该组分**全电离**。
这条把中心拉回全电离（μ = 0.8537，与理想气体值 0.854 一致），而在稀薄包层完全不起作用。`[src]`：Debye-Hückel
对 Saha 方程的修正（Kippenhahn, Weigert & Weiss ch. 15 的标准处理）。

**验收**（`fluid_saha_eos`）：
- 太阳中心：n_e = 6.13e25 cm⁻³、**μ = 0.8537**（理想气体 0.854）、P = 2.308e16 Pa（SSM 2.335e16 Pa）；
- 冷层（ρ=1e-6、T=6e3）：H⁺/H = 1.6e-6（中性），μ = 1.280（中性值 1.29）；
- 定密度升温：μ = 1.280 → 1.278 → 0.972 → 0.621（中性→电离）；
- **∇_ad：深内部 0.3999（0.4），氢电离区 0.2405**——电离潜热使 EOS 变软，正是包层结构所需；
- 密度反演往返误差 < 1e-6。

**换上它之后**：L = **1.025 L☉**（太阳的 2.5%）、R = 0.595 R☉（此前 0.539），
m/M = 0.19 处 T 差 1.6%、ρ 差 8%。剩余偏差集中在 m/M ≳ 0.9 的包层（T 偏高约 2 倍），
那里同时有混合长、表面边界条件与 EOS 细节（配分函数、Coulomb 自由能）三件事。

### 4.3f 边值求解的尝试与结论（本轮）

按 (4.3e) 的定位，把中心 (Pc, Tc) 放开、用光球边界条件打靶：

  残差 r₁ = log(P(M)/P_phot)，r₂ = log(T(M)/T_eff)，P_phot = (2/3)g/κ_surf，T_eff = (L/4πR²σ)^{1/4}

**结果：不收敛，而且失败方式本身是信息**。10 次牛顿迭代后 r₁ ≈ +12…+14、r₂ ≈ +1.6，
即模型积分到 m = M 时压力仍高达 3e16 Pa（光球应为 3.7e4 Pa）——**模型根本没有"表面"**：
它在包层里一直是高温高密的近等温结构，所以打靶找不到根。

这与 §4.3e 的结论一致并把它推进一步：**包层 κ 偏低 5 倍不只是"半径短"，它让模型没有光球，
因此任何边值求解都不可能收敛**。换句话说，自洽模型的前提是先让包层的不透明度正确到 ~1%
（H⁻/分子/尘粒贡献 + 表的边界外推），而这需要比"够用的对照"更高精度的输入。

**本会话的取舍**：把可控的部分做到可验证、把不可控的部分量化并定位。具体地，
`solve_solar_model` 已实现（含阻尼牛顿与数值雅可比），留作后续接入更完整的不透明度后的求解器；
本轮不把它接进 ctest（不宣称一个未收敛的结果为通过）。

### 4.3g 状态与回归基线

- **回归基线**：ctest `fluid_solar_model`（`solar_compare_plot.py --check`）把当前模型的积分输出钉住
  （L = 1.025 L☉、R = 0.592 R☉，容差为区间），防止后续对 EOS/不透明度/混合长的改动悄悄移动它。
  这是**回归**判据，不是科学判据——模型已知偏致密，见 §4.3e。
- **表述的取舍（本轮实测）**：把状态从 (ρ,T) 换成标准的 (r,P,T,L)（EOS 反演得 ρ）在物理上更正确，
  在软包层也更鲁棒，但本轮实现里 EOS 反演的牛顿以"上一次的 ρ"作初值、又被 RK4 的中间级污染，
  结果 L 从 1.025 漂到 1.125 L☉。**已回退**，把"设计一个单调可靠的 EOS 反演（log ρ 上的
  safeguarded Newton + 二分兜底）"列为下一次的起点，而不是把一个未验证的表述留在树里。

### 4.3h 表述差异的根因：不完整的链式法则（已解决）

上一轮记录的 10% 差异**已找到根因**，不是噪声、不是离散化，而是**公式错误**：

(ρ,T) 表述把密度当作演化变量，用 dρ/dm = (dP/dm)/(∂P/∂ρ)|_T 换算。但**温度也沿质量坐标变化**，
正确的全导数是

  dρ/dm = (∂ρ/∂P)|_T · dP/dm + (∂ρ/∂T)|_P · dT/dm                                        (4.12)

漏掉第二项就等于把恒星当成等温的来换算密度。修正后：

| 表述 | R | L |
|---|---|---|
| (ρ,T)，漏掉 (∂ρ/∂T) 项 | 0.595 R☉ | 1.025 L☉ |
| **(r,P,T,L)，正确** | **0.539 R☉** | **1.125 L☉** |

**收敛性研究确认这不是截断误差**：两种表述各自在 n_steps = 400/1600/6400 下给出**完全相同**的结果
（都收敛了），但**收敛到不同的极限**——数学上不一致，只能有一个对。正确的是标准的 (r,P,T,L)。

**处理**：(r,P,T,L) 成为默认表述；(ρ,T) 分支保留在代码里并带警示注释，作为这次错误的记录
（`formulation="density"`）；回归基线 `fluid_solar_model` 更新为 **L = 1.125 L☉、R = 0.539 R☉**——
数字比之前"好看"的 1.025 差，但它是我们这套物理的**正确**答案。

**方法论教训**：一个换表述就变 10% 的模型，先怀疑公式、再怀疑物理。这一轮花了两次尝试，
但如果把 1.025 当成"已达标"继续校准，后面所有结论都会建在一个漏项上。

### 4.3h-old 表述差异的初次记录

把状态从 (ρ,T) 换成标准的 (r,P,T,L)（EOS 反演得 ρ，反演用 §4.3g 要求的"带括号保护的牛顿 + 二分兜底"，
已实现为 `eos.density_for_pressure_safe` 并通过自检）后，模型给出 **R = 0.539 R☉、L = 1.125 L☉**，
而 (ρ,T) 表述给出 **R = 0.592 R☉、L = 1.025 L☉**。

两者在 m/M = 0.19 处的 T 完全相同（1.148e7），因此差异不在内核——它出现在外层，并在积分中被放大
（包层 ∇ 的链式反馈：κ ∝ T^{−3.5}、∇ ∝ κ）。**这不是数值噪声，而是同一组方程的两个离散实现给出了不同的恒星。**

处理方式：**保留 (ρ,T) 表述作为已交付结果的表述**（图与回归基线 `fluid_solar_model` 都是它，
L = 1.025 L☉、R = 0.592 R☉），把"两个表述的差异定位到具体外层区间并给出收敛性依据（步长加密、
EOS 反演精度、RK4 阶）"列为**下一步的第一件事**——在一个连表述都没对齐的模型上做校准是没有意义的。

这也是一条方法论记录：**同一个物理问题换表述后结果变了 10%，说明当前的包层对离散化细节过度敏感**，
而敏感性本身正是"包层物理还缺东西"的又一个指标。

### 4.3i 自洽拟合的尝试（本轮）

在修正后的 (r,P,T,L) 表述上重做光球边界拟合。二维牛顿太脆弱（模型在 m = M 处压力仍有 e14 倍偏差、
质量亏损 20–40%），改为**嵌套割线**：

- 内层：固定 Tc，移动 log Pc 使"压力降到 P_phot 处的温度"等于该处 (R,L) 的有效温度 T_eff；
- 外层：移动 log Tc 使光球落在 m = M（质量亏损 → 0）。

这比二维牛顿稳健（每步只解一维），但它把问题变成了**大量模型积分的开销**：单次积分（n = 200）
在本环境需 **46 s**，主因是纯 Python 的 Saha EOS（每次 RHS 约 13 次 `state()`，每次 ~3 ms）。
本轮已把 EOS 反演从 40 次二分改为括号内牛顿（0.33 s/100 次，快 120 倍）、并把 ∇_ad 改为每步缓存，
但单次积分仍在几十秒量级——**拟合要在后台跑，不能在一轮里等**。

**实测（3×3 次嵌套，约 12 分钟）**：割线把质量亏损压到了 0（m_surf/M = 1.000 ✓），
但**光球温度对不上**：模型在"光球"处 T = 6.4e6 K，而该处 (R,L) 给出的 T_eff = 1.0e4 K——
**差 600 倍**。

这不是拟合算法的问题，而是**模型外层根本降不到低温**：包层里温度梯度太小（κ 偏低 → ∇_rad 偏小
→ 温度几乎不随压力下降）。这与 §4.3e/4.3h 的结论一致，也说明**在包层物理补齐之前，任何拟合都不会
给出太阳**。

**结论与定位**：自洽校准模型的前提依次是
1. 包层不透明度正确到 ~1%（H⁻ 全温区、分子/尘粒、OPAL 表边界外推）；
2. 单次模型积分足够快（当前 46 s/次，纯 Python EOS；做 (X₀, α_MLT) 校准需要几十次评价）；
3. 光球边界与 MLT 的细节（混合长、超绝热层）。

这三条都是**工具/物理的实质工作**，不是调参能绕过的。本会话已把 (2) 的 EOS 部分加速 120 倍
（反演改括号内牛顿）、把 ∇_ad 改为每步缓存，但 Python 实现下仍不够快。

### 4.3j EOS 反演的初值依赖（本轮修正）

profile 显示单次模型积分 43–52 s、其中 **326,350 次 `state()` 调用**、每次反演约 **65 次 EOS 求值**。
深挖发现 `density_for_pressure_safe` 的牛顿步被限制在 ±0.25 decade 且只跑 40 次，**从远处起步时收敛不完**
→ **反演结果依赖初值**。这不是模型的问题，但它是"结果可能悄悄依赖数值细节"的隐患，必须修掉。

修正：括号从初值**逐 decade 生长**到包含目标，牛顿步**不许越出括号**，收敛到 1e-13；自检要求
"不同初值给出同一结果"（实测 153.777563 在 1e-3…1e6 四个初值下完全一致，P 往返 1e-10）。

**这次没有改变模型**：用真实组分剖面重跑，仍是 **L = 1.125 L☉、R = 0.539 R☉**——说明此前的初值恰好够好。
（中途我用了一份"近似组分"做快速测试，得到 L = 2.106 的假结果；**已核对确认那是测试脚本的组分被简化所致**，
不是模型变化。这条也记在这里：**不要用简化输入去验证一个对输入敏感的量**。）

**这是同一个教训的第三次出现**：(ρ,T) 的链式法则漏项、∇_ad 的 4 倍系数、这次的初值依赖——
每次都是"数值实现"冒充"物理结论"，每次都靠"换算法/换初值/换表述应给出同样结果"这条原则抓出来。

## 6. 与既有实现的集成细节（实测记录）

写 `NewtonGravitySolver` 时撞到的两个约束，记下来避免重复踩：

1. **ablastr 的 `computePhi` 要求 β 的各分量 < 1**（断言在 `PoissonSolver.H`）。
   它自己承担 4π 因子，所以本插件取 **β = 1/(4π)**、右端 `G(ρ − ⟨ρ⟩)`，
   于是 `∇·(β∇φ) = G(ρ−⟨ρ⟩)` 等价于 `∇²φ = 4πG(ρ−⟨ρ⟩)`。
2. **不传 `boundary_handler` 时，ablastr 默认把域边界设为 Dirichlet**（`PoissonSolver.H:396-403`）。
   周期盒子因此触发 AMReX 的断言（要求 LinOp 全周期）。正确接法是提供一个带
   `lobc`/`hibc` 的 handler，全维填 `LinOpBCType::Periodic`。
3. **`open` 边界只对非周期方向取 Dirichlet**：AMReX 断言算符边界类型要与 Geometry 的周期性一致
   （`MLLinOp.H:1775`），所以周期性平面（如等温薄层的横向）必须保持 `Periodic`，
   否则求解直接 abort。`solvePotential` 里现在按 `geom.isPeriodic(d)` 逐方向判断。
4. **Dirichlet 边界数据位于"面"上，不是网格中心**（实测）。`MLMGBndry::setBoxBC` 对物理边界
   把数据位置偏移硬编码为 0，`setPhysBndryValues` 只是把 `phi` 的鬼格值搬进边界数组，
   所以调用方必须把鬼格值填成**该面处**的势（法向坐标夹到域边界，切向取网格中心），
   算符再用 `2φ_face − φ_内` 外推。若填成鬼格中心的值，等价于把边界平移半格，
   实测误差立刻变成一阶（球算例 5%、收敛阶 1.0）。`setDomainBCLoc` 在这条路径上没有
   改变结果，因此实现里干脆不用它，只依赖默认的"面"约定。
5. **体积分数必须从格子下角起算**。子采样写成 `x + (a+0.5)h`（漏掉 `−dx/2`）会让
   数字化后的球整体偏移半格，产生一个偶极矩；质量仍然守恒（差值 1e-5），但外部场错 2%~7%，
   而且表现为一阶收敛。这个 bug 在球算例上曾伪装成"边界条件错"，查了三轮才对上账：
   把子采样改回 `x − dx/2 + (a+0.5)h` 后，直接求和与解析解立刻回到 1e-5 量级。
