# A6.3 IAmrPolicy

## 接口

`Source/Runtime/IAmrPolicy.H`：

```cpp
class IAmrPolicy {
    virtual void tag(int lev, TagBoxArray&, Real time, int ngrow) = 0;
    virtual DistributionMapping
    makeDistributionMap(int lev, BoxArray const&) = 0;
    virtual void postProcessBaseGrids(BoxArray& ba0) const = 0;
};
```

只做决策，不创建 level、不迁移数据、不触发 regrid。

## 接入

`WarpX::SetAmrPolicy()` 安装策略。

三个钩子：

```cpp
WarpX::ErrorEst
  -> m_amr_policy->tag(...)

WarpX::MakeDistributionMap
  -> m_amr_policy->makeDistributionMap(...)

WarpX::PostProcessBaseGrids
  -> m_amr_policy->postProcessBaseGrids(...)
```

未安装策略时使用原有逻辑。

## 限制

- 只提供策略注入，不提供外部 `.so` 的 policy ABI；
- policy 仍可访问 WarpX 指针，不是纯数据接口；
- 未替换初始化路径中所有 base-grid 逻辑，只在 `PostProcessBaseGrids` 决策点接入。
