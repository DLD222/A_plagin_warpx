## A7.2.1 Diagnostics 独立插件

目标：

```text
Source/Plugins/Diagnostics/
```

规则：

```text
不 include Particles/*
不持有 WarpXParticleContainer 具体类型
只通过 RuntimeData/DataBus 读取
```

前置：

```text
ParticleDiag / BT / Full / BoundaryScraping
剩余向下转换清零
```

验收：

```text
Diagnostics 插件可禁用
PicEm 不 include Diagnostics
```

---

## A7.2.2 Collision 独立插件

目标：

```text
Source/Plugins/Collision/
```

规则：

```text
不 include Diagnostics/*
不直接持有 PicEm 私有容器
只通过物种/字段接口工作
```

前置：

```text
CollisionSpeciesTable 不再保存 WarpXParticleContainer*
ParticleThermalizer 不再直接构造 WarpXParIter
```

验收：

```text
删除 Collision 插件，PicEm 仍可编译运行
```

## A7.2.3 插件边界检查

```text

```

规则：

```text

Plugin A 不得 include Plugin B/
每个 Plugin 自带 Package 注册
```
