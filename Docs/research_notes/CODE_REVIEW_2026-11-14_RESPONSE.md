## 审查之外新发现的缺陷（不在 F-01～F-11 内）

**N-01：1D 散度写成两项，读到越界内存。** 提交 `7e5bb6d`。
`rho_medium` 种子、每步传导电荷推进、Gauss 残差诊断三处都用
`(Dx(i)-Dx(i-1))/dx + (Dz(i,j)-Dz(i,j-1))/dz`，而 1D 只有一个轴：第一项重复计一次，
第二项读 `j-1`（1D 里 j 恒为 0，即 index −1，落在相邻分配里）。结果是所有 1D 宏观算例都报
`max|divD| = max|rho_m| = 1.733188866e+267`，且在 σ=0 时静默——种子值不进入更新，
只有诊断看得见。

修复后（PEC / 周期 / 周期+界面+subpixel 三种 1D 算例）：

```
[GAUSS] step 20  max|divD - (rho_p + rho_m)| = 0  max|divD| = 0  max|rho_m| = 0
```

2D 对照（本来就正确）：`max|divD| = 5.9e-17`，即机器零；无自由电荷时 divD = 0 是应有结果。

**N-02：节点材料数组未清零。** AMReX 不初始化新 MultiFab，标量材料分支只写对角，
eps/sigma/eps⁻¹ 的非对角分量本来是未初始化值。已在分配后 `setVal(0)`（同一次提交）。
