# A3.1 InitData 阶段化调研

> 目标：把 `WarpX::InitData()` 的顺序调用映射到标准 `StagePoint`，再由 `StagePlan`
> 排序；A3.1 只做映射和阶段方法，不在这一轮引入完整调度器。

## 1. 当前 InitData 顺序

`Source/Initialization/WarpXInitData.cpp`：

| 顺序 | 调用 | 依赖 | 目标阶段 |
|---:|---|---|---|

| 2 | `ComputeDt` | geometry | `Init` |

| 4 | `InitDiagnostics` / `PostRestart` | fields 已分配 | `AfterInit` |

| 8 | `BuildBufferMasks` | fields | `AfterInit` |

| 10 | `electrostatic_solver->InitData` | fields/rho | `FieldSolve`（初始化子阶段） |

## 2. 必须保持的依赖

1. **dt 先于 PML/guard cells**；
2. **fields 先于 diagnostics/PML factors**；
3. **ES/hybrid 在场分配之后**；
4. **external fields 在初始场求解之后**；
5. **首次诊断在最后**；
6. restart 路径跳过 `ProjectionCleanDivB` 和初始场求解。

## 3. 目标 StagePoint

```cpp
enum class Stage {
    BeforeInit,
    Init,
    AfterInit,
    BeforeFieldSolve,
    FieldSolve,
    AfterFieldSolve,
    BeforePush,
    Push,
    AfterPush,
    BeforeCollisions,
    Collisions,
    AfterCollisions,
    Diagnostics,
    Finalize
};

struct StagePoint {
    Stage stage;
    int sub;
};
```

具体子位点：

```
Init/0             ComputeDt
Init/1             InitFromScratch/Checkpoint
AfterInit/0        InitDiagnostics
AfterInit/1        ComputePMLFactors
AfterInit/2        BuildBufferMasks
AfterInit/3        ProjectionCleanDivB
FieldSolve/0       electrostatic InitData
FieldSolve/1       hybrid InitData
FieldSolve/2       ComputeSpaceChargeField
AfterFieldSolve/0  AddExternalFields
Diagnostics/0      FilterComputePackFlush
```

## 4. 分步

### A3.1a StagePoint 类型

- `Runtime/StagePoint.H`：`Stage`/`StagePoint`/`StagePlan` 最小定义；
- 单元测试只验证枚举/排序 API；
- 不改变 InitData 行为。

### A3.1b InitData 阶段方法

把顺序代码提取为：

```cpp
InitData_BeforeInit();
InitData_Init();
InitData_AfterInit();
InitData_FieldSolve();
InitData_Diagnostics();
```

每个方法内部仍按当前顺序；`InitData()` 只负责调用。**行为逐位不变**。

### A3.1c StagePlan 执行

用 `StagePlan` 按 `StagePoint` 排序调用上述方法；此时才引入调度。

## 5. 验收

- A3.1a：类型可编译，单元测试通过；
- A3.1b：`test_2d_langmuir_multi` / EB / PSATD / restart 全部通过，数值不变；
- A3.1c：StagePlan 拓扑顺序与当前顺序一致，日志打印每个阶段。

## 6. 当前不做

- 不把 `WarpX::InitData` 整体重写；
- 不把 diagnostics/PML 变成插件；
- 不在 A3.1 引入动态加载。

这些属于 A3.3/A5。
