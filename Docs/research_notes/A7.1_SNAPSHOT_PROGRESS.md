# A7.1 渐进依赖倒置：配置快照

## 1. 本轮改动

新增：

```text
Source/Core/Runtime/RuntimeConfigSnapshot.H
Source/Plugins/PicEm/Modules/PicEm/RuntimeConfigSnapshotBridge.cpp
```

- Core 只声明 `RuntimeConfigSnapshot`，不 include `WarpX.H`；
- 插件侧 `FromLegacy()` 负责从 WarpX 填充；
- `Runtime` 持有快照，`RuntimeContext` 暴露：

```cpp
const RuntimeConfigSnapshot* config_snapshot;
```

- 现有 live `RuntimeConfig` 保留给 BTD 等旧路径。

## 2. 快照字段


## 3. 为什么不是一次性替换

之前一次性把 49 个 getter 改成快照，导致：

```text
GridType/边界默认值错误
BTD computeRho segfault
```

因此采用渐进方式：

```text
live RuntimeConfig 保留
新增 RuntimeConfigSnapshot
模块逐步改用 snapshot
BTD 最后迁移
```

## 4. 验证

```text
默认 runtime 5/5 PASS
FFT runtime 7/7 PASS
ASAN runtime 5/5 PASS
context.config_snapshot 指针检查 PASS
snapshot 与 WarpX 当前值一致性检查 PASS
```

## 5. 下一步

```text
1. PicEm 模块改用 ctx.context->config_snapshot
2. Diagnostics 模块读取 snapshot 中的稳定字段
3. BTD 保留 live，最后迁移
4. 全部迁移后删除 live getter 直接读 WarpX
```
