# A6.1 RemakeLevel 任意 BoxArray：源码分析

## 现状

`WarpX::RemakeLevel`：

- 当 `ba == boxArray(lev)`：
  - 只换 DistributionMapping
  - `m_fields.remake_level(lev, dm)`
  - 重建 EB/PML/PSATD/costs/masks
- 当 `ba != boxArray(lev)`：

```cpp
WARPX_ABORT_WITH_MESSAGE("RemakeLevel: to be implemented");
```

## 为什么不能直接复用现有路径

`MultiFabRegister::remake_level(lev, new_dm)` 的语义是：

```text
同一 BoxArray，换 DistributionMapping
```

它内部按相同 index space 重新分配并复制，不做 BoxArray 变化迁移。

任意 BoxArray 变化需要：

1. 保存旧 level 的每个 MultiFab；
2. 按新 BoxArray/DM 分配；
3. 把旧数据从“旧 box 与新 box 的交集”搬到新 box；
4. 新覆盖但旧不存在的区域，从 coarse 插值；
5. 旧存在但新不覆盖的区域丢弃；
6. 重建 EB/PML/PSATD/costs/masks/particles/diagnostics。

## AMReX 工具的限制

`amrex::MultiFab::Copy(dst, src, ...)` 要求：

```text
dst.boxArray() == src.boxArray()
```

因此不能直接：

```cpp
MultiFab::Copy(new_mf, old_mf, ...);
```

`MultiFabRegister` 也没有提供：

```cpp
remake_level(lev, new_ba, new_dm)
```

## 可行方案

### 方案 A：逐 Fab 交集拷贝

对 new 的每个 Fab：

1. 找到旧 BA 中与之重叠的 box；
2. 在本地/远端执行 `FabArray::ParallelCopy` 或手工 `FAB::copy`；
3. 交集外区域从 coarse 插值。

优点：保留旧细层数据。
缺点：需要处理 MPI owner、周期边界、EB、mask、PML。

### 方案 B：整层从 coarse 重新填充

```text
AllocLevelData(new_ba)
InterpFromCoarseLevel(E/B/J/rho)
```

优点：实现简单，A6a 已有插值代码。
缺点：**丢弃旧细层数据**，对动态加密的物理精度有损，不能作为高质量实现。

### 方案 C：复用 AMReX AmrLevel 路径

WarpX 不是 `AmrLevel`，无法直接调用 `AmrLevel::RemakeLevel`。

## 结论

A6.1 不能只删 abort。

必须先实现一个**逐 Fab 交集迁移**函数：

```cpp
copyOverlap(dst_new_ba, src_old_ba, ngrow)
```

再处理：

- 新区域 coarse 插值；
- EB factory；
- PML；
- PSATD spectral solver；
- buffer masks；
- particle `AllocData/Redistribute`；
- diagnostics `ResizeLevels`。

## 当前决定

不在没有交集迁移实现前删 abort。
A6.1 保持 pending。
