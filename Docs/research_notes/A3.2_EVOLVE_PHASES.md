# A3.2 Evolve/OneStep 阶段化调研

> 目标：只对显式电磁 PIC 路径建立 `StagePlan`；隐式、Hybrid、JRhom 保留原路径。
> A3.2 不在这一轮重写 `OneStep_nosub`。

## 1. 当前显式 PIC 顺序

`WarpX::OneStep_nosub`：

| 顺序 | 调用 | 目标阶段 |
|---:|---|---|
| 1 | `ExecutePythonCallback("beforedeposition")` | `BeforePush` |
| 2 | `mypc->doCollisions` | `BeforeCollisions` |
| 3 | `PushParticlesandDeposit` | `Push` |
| 4 | `ExecutePythonCallback("afterdeposition")` | `AfterPush` |
| 5 | `SyncCurrentAndRho` / `FinalizeRho` / `FinalizeJ` | `AfterPush` |
| 6 | moment fluid current | `AfterPush` |
| 7 | PML J copy/damp | `BeforeFieldSolve` |
| 8 | `ExecutePythonCallback("beforeEsolve")` | `BeforeFieldSolve` |
| 9 | PSATD / Yee E,B push | `FieldSolve` |
| 10 | PML damp / fill boundaries | `AfterFieldSolve` |

## 2. 不统一的分支

| 分支 | 原因 |
|---|---|
| `m_implicit_solver` | 由隐式 solver 自己控制时间步 |
| `electromagnetic_solver_id == HybridPIC` | Hybrid 有独立 E/B 推进 |
| `m_JRhom` | 电流/rho 更新顺序不同 |
| `m_collisions_split_momentum_push` | 碰撞嵌在动量推进中间 |

这些分支在 A3.2 保持原代码，不套 `StagePlan`。

## 3. 分步

### A3.2a 显式路径阶段方法

把 `OneStep_nosub` 的连续块提取为：

```cpp
OneStep_BeforePush();
OneStep_Push();
OneStep_AfterPush();
OneStep_BeforeFieldSolve();
OneStep_FieldSolve();
OneStep_AfterFieldSolve();
```

顺序不变；不改变分支条件。

### A3.2b StagePlan 执行

用 `StagePlan` 调用上述方法；仅显式路径。

### A3.2c 验证

- `test_2d_langmuir_multi` 数值不变；
- `test_2d_pml_x_yee`；
- PSATD `test_2d_langmuir_multi_psatd`；
- 隐式/Hybrid 测试保持原路径。

## 4. 当前决定

A3.2 先做 A3.2a 的结构提取，不做阶段调度器。

原因：`OneStep_nosub` 内 `dt`、`a_cur_time`、`do_pml` 等状态跨块使用，直接搬进独立方法会引入大量参数；先提取为成员方法、保持局部变量在同一函数内，风险最低。

## 5. 验收

- A3.2a：所有测试通过，数值不变；
- A3.2b：阶段顺序日志与当前一致；
- A3.2c：显式/PSATD/PML 回归通过；
- 隐式/Hybrid 不在 A3.2 改动。
