# A6.4 动态加密 + on_regrid 回归门

## on_regrid 回调

`IHandler` 新增：

```cpp
virtual void on_regrid (StageContext& /*ctx*/) {}
```

`PluginHost::notify_regrid(ctx)` 按 handler 顺序调用。

`WarpX::RunRegridStage(step)`：

```cpp
regrid(0, cur_time);
RunRegridStage(istep[0]);
multi_diags->ResizeLevels(finest_level);
...
```

## 限制

- on_regrid 只在 Runtime 安装了 PluginHost 时调用；
- 物理门阈值 5e-2（场）和 1e-1（总场能）是单步比较，不是长期守恒；
- 未使用 reduced-diagnostics 总场能作为门：新增 level 会改变总能量统计口径，
  不能直接当作守恒量；
- `dynamic_regrid_remake` 已开启粒子输出。
