# A6.4 动态加密 + on_regrid 回归门

## on_regrid 回调

`IHandler` 新增：

```cpp
virtual void on_regrid (StageContext& /*ctx*/) {}
```

`PluginHost::notify_regrid(ctx)` 按 handler 顺序调用。

`WarpX::RunRegridStage(step)`：

```cpp
regrid(0, cur_time);
RunRegridStage(istep[0]);
multi_diags->ResizeLevels(finest_level);
...
```

## 限制

- on_regrid 只在 Runtime 安装了 PluginHost 时调用；
- 物理门阈值 5e-2（场）和 1e-1（总场能）是单步比较，不是长期守恒；
- 未使用 reduced-diagnostics 总场能作为门：新增 level 会改变总能量统计口径，
  不能直接当作守恒量；
- `dynamic_regrid_remake` 已开启粒子输出。

## 稳定算例：uniform B 长期守恒

新增：

```text
Examples/Tests/dynamic_regrid/inputs_test_2d_dynamic_regrid_uniform_b
Examples/Tests/dynamic_regrid/analysis_uniform_b.py
```

配置：

```text
2D periodic
无粒子
B0 = (0, 0, 1)
E0 = 0
level1 在 step 15 首次出现
```

结果：

```text
step 14  level0
step 15  level1
step 15..40 总场能恒为 4096
rel < 1e-12
```

这是真正的长期守恒门，不再使用 Langmuir 的强衰减数据。

## 同时修复的初始化 bug

`WarpX::AddExternalFields` 和 `InitData_FieldSolve` 原来按：

```cpp
max_level
```

遍历，假设所有 level 已存在。

延迟加密时，初始化只有 level0，访问：

```text
Efield_fp[level=1]
```

会抛：

```text
MultiFabRegister::get name does not exist
```

修复：

```cpp
AddExternalFields: get_mr_levels_alldirs(..., lev)
InitData_FieldSolve: for lev <= finestLevel()
```
