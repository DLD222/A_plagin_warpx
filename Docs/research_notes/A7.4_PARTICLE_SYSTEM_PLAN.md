## 2. 是否符合两个根本要求

### 插件化

不满足：

```text
Particles 不是独立插件
Particles 与 PicEm 容器/场/初始化直接耦合
Collision/QED 不是独立插件
```

### 模块化

部分满足：

```text
Collision/Pusher/Deposition/Gather/Resampling 已有目录
```

不满足：

```text
WarpXParticleContainer 是上帝类
MultiParticleContainer 是上帝类
PhysicalParticleContainer 混合注入/推进/沉积/边界
Deposition 目前几乎没有独立 CPP
Pusher 只有 Implicit 一个独立 CPP
```

## 7. 风险

```text
WarpXParticleContainer 与其他模块共享粒子状态
PhysicalParticleContainer 混合注入/推进/沉积
ParticleCreation 与 parser/openPMD 耦合
Collision 依赖粒子 tile/SoA
QED 依赖粒子属性与场
```

处理原则：

```text
先契约后迁移
每步可编译
每步四维回归
禁止用目录移动冒充完成
```
