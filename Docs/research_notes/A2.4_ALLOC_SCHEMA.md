# A2.4 AllocLevelData schema 化调研

> 结论：`AllocLevelData` 有 **128 处** `m_fields.alloc_init`，不能一次替换。
> 按分配组拆成 A2.4a–e，先做 base E/B/J，再做 solver/EB/平均量/诊断缓冲。

## 1. 现状

`Source/WarpX.cpp::AllocLevelData` 中 128 处分配，按用途分组：

| 组 | 数量（约） | 例子 | 依赖 |
|---|---:|---|---|
| base EM | 20 | `Bfield_fp`, `Efield_fp`, `current_fp` | nodal flag、`ngEB/ngJ` |
| PSATD 专用 | 20+ | `E_old`, `B_old`, `current_fp_nodal`, `current_fp_vay`, `rho_fp` | `WARPX_USE_FFT`、solver id |
| EB/ECT | 30+ | `edge_lengths`, `face_areas`, `area_mod`, `Venl`, `ECTRhofield`, `dual_*` | `AMREX_USE_EB`、ECT |
| 平均/旧场 | 6 | `Bfield_avg_fp`, `Efield_avg_fp` | time averaging |
| 电流缓冲 | 6 | `current_store`, `current_fp_non_suborbit` | subcycling |
| 诊断/材料 | 10 | `rho_fp`, `phi_fp`, `rho_medium_fp` | solver/medium |
| hybrid/其它 | 剩余 | `vector_potential_*`, `distance_to_eb` | Hybrid/QED/EB |

## 2. 不能直接套 FieldSpec 的原因

1. **nodal flag 是运行期决定的**：`Ex_nodal_flag` 等由 solver/grid type 计算，不是静态 schema；
2. **ngrow 不是常量**：`ngEB/ngJ/ngRho` 来自 `guard_cells`，依赖 solver/subcycling/PML；
3. **分配顺序有依赖**：`guard_cells.Init` 必须先于大部分分配；PSATD 的 `rho_fp` 又依赖 `current_fp`；
4. **条件编译**：PSATD/EB/ECT 的字段只在特定构建存在；
5. **别名**：部分字段是 `alias_init`，不能按普通 spec 再分配。

## 3. 目标接口

```cpp
struct FieldAllocSpec {
    FieldKey key;
    int ncomp;
    amrex::IntVect nodal;
    amrex::IntVect ngrow;
    bool checkpoint;
    bool moving_window_shift;
    std::string alias_of;
};

class FieldSchema {
public:
    void declare(FieldAllocSpec);
    [[nodiscard]] const FieldAllocSpec& get(FieldKey) const;
    [[nodiscard]] bool contains(FieldKey) const;
};
```

分配 helper：

```cpp
void WarpX::AllocLevelField (const FieldKey& key, int lev,
                             const amrex::BoxArray& ba,
                             const amrex::DistributionMapping& dm,
                             const amrex::IntVect& nodal,
                             const amrex::IntVect& ngrow);
```

`FieldSchema` 只描述，不拥有；`MultiFabRegister` 仍是唯一 owner。

## 4. 分步

### A2.4a base EM

替换：

```
Bfield_fp[0..2]
Efield_fp[0..2]
current_fp[0..2]
```

9 个字段，验证 `ngEB/ngJ`、nodal flag、checkpoint 标记。

### A2.4b PSATD

`E_old/B_old/current_fp_nodal/current_fp_vay/rho_fp` 等，仅 FFT 构建。

### A2.4c EB/ECT

`edge_lengths/face_areas/area_mod/Venl/ECTRhofield/dual_*`，仅 EB 构建。

### A2.4d 平均/缓冲

`Bfield_avg_fp/Efield_avg_fp/current_store/current_fp_non_suborbit`。

### A2.4e 剩余

`phi_fp/rho_medium/vector_potential_*/distance_to_eb` 等。

## 5. 验收

- 每个字段的 `FieldAllocSpec` 与实际 `alloc_init` 参数逐项一致；
- `FieldSchema::declare` 重复键报错；
- `test_2d_langmuir_multi` 逐位不变（checksum 忽略，但 analysis 数值不变）；
- PSATD/EB 构建分别编译通过；
- 不再出现无 spec 的裸 `alloc_init`（A2.4e 后）。

## 6. 当前决定

先写 `FieldSchema` + A2.4a 的 9 个 base 字段，不碰 PSATD/EB。
这样即使 schema 设计有误，也只影响 base 分配，能快速回退。
