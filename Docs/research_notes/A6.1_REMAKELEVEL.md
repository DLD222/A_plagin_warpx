# A6.1 任意 BoxArray 的 RemakeLevel

## 实现

### 1. 资源重建抽取

从原同 BA 分支抽出：

```cpp
WarpX::RecreateLevelResources(lev, ba, dm)
```

负责：

- EB update masks / field factory
- spectral solver
- costs
- PML
- buffer masks
- `SetDistributionMap`
- diagnostic functors

同 BA 路径：

```cpp
m_fields.remake_level(lev, dm);
RecreateLevelResources(lev, ba, dm);
```

### 2. 任意 BoxArray

```cpp
保存旧 level 所有 MultiFab
ClearLevel(lev)
AllocLevelData(lev, ba, dm)
InitLevelData
core 字段从 coarse 插值
ParallelCopy 旧交集覆盖
RecreateLevelResources
```

新增：

```cpp
MultiFabRegister::get_internal(name)
```

用于按 internal name 保存/恢复字段。

### 3. 粒子

regrid 后：

```cpp
GetParGDB()->ParticleBoxArray(lev)
GetParGDB()->ParticleDistributionMap(lev)
mypc->SetParticleBoxArray
mypc->SetParticleDistributionMap
mypc->AllocData
mypc->Redistribute
mypc->defineAllParticleTiles
```

### 4. 时间相关 tagging

新增：

```text
warpx.fine_tag_lo_2
warpx.fine_tag_hi_2
warpx.refine_region_change_time
```

用于触发已有 level 的 BoxArray 改变。

## 粒子输出 grid 映射（未解决）

重新打开 `write_species` 后：

```text
diag1000008
yt: index 2 is out of bounds for axis 0 with size 2
```

已尝试：

1. `mypc->AllocData/Redistribute/defineAllParticleTiles`；
2. 先 `defineAllParticleTiles` 再 `Redistribute`；
3. `GetParGDB()->SetParticleBoxArray/SetParticleDistributionMap`；
4. `mypc->SetParticleBoxArray/SetParticleDistributionMap`。

均未消除旧 level 的 particle grid id。

判断：

- `ParticleContainer::resizeData` 只扩容；
- 旧 level 的 particle tiles/AoS `grid` 字段未完整重建；
- 输出写出的 grid id 仍超过新 field grid 数。

因此 `dynamic_regrid_remake` 仍保持：

```text
write_species = 0
```

该缺陷登记为 A6.2 前置修复项。
