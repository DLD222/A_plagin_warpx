# A6.1/A6.2 任意 BoxArray 的 RemakeLevel

## 实现

### 1. 资源重建抽取

从原同 BA 分支抽出：

```cpp
WarpX::RecreateLevelResources(lev, ba, dm)
```

负责：

- EB update masks / field factory
- spectral solver
- costs
- PML
- buffer masks
- `SetDistributionMap`
- diagnostic functors

同 BA 路径：

```cpp
m_fields.remake_level(lev, dm);
RecreateLevelResources(lev, ba, dm);
```


## A6.2 覆盖

A6.2 的“通用 RemakeLevel（任意 BoxArray）”由
`RecreateLevelResources + ParallelCopy` 实现；
`LevelResources` 仍只拥有部分资源，剩余 EB/mask 资源逐步迁移。

## 限制

- 当前 remake 测试关闭粒子输出（`write_species=0`）；
- 粒子容器 BA/DM 已更新，但 FullDiagnostics 的粒子输出 buffer 在已有 level 改变 BA 时尚未重建；
- 只验证 FullDiagnostics。

## 粒子输出 grid 映射（已修复）

重新打开 `write_species` 后：

```text
diag1000008
yt: index 2 is out of bounds for axis 0 with size 2
```

已尝试：

1. `mypc->AllocData/Redistribute/defineAllParticleTiles`；
2. 先 `defineAllParticleTiles` 再 `Redistribute`；
3. `GetParGDB()->SetParticleBoxArray/SetParticleDistributionMap`；
4. `mypc->SetParticleBoxArray/SetParticleDistributionMap`。

均未消除旧 level 的 particle grid id。

判断：

- `ParticleContainer::resizeData` 只扩容；
- 旧 level 的 particle tiles/AoS `grid` 字段未完整重建；
- 输出写出的 grid id 仍超过新 field grid 数。

根因不是粒子容器，而是输出诊断：

- `FullDiagnostics::m_geom_output` / `m_mf_output` 仍按旧 level BA；
- 粒子按新 BA 写出，字段仍按旧 BA，grid id 不一致。

修复：

```cpp
Diagnostics::RemakeLevel(lev)
FullDiagnostics::RemakeLevel
MultiDiagnostics::RemakeLevel
```

regrid 后：

```cpp
for (lev) multi_diags->RemakeLevel(lev);
multi_diags->ResizeLevels(finest_level);
```

并按字段 BA 重设粒子 BA/DM。

`dynamic_regrid_remake` 已恢复 `write_species`，粒子可读。

### 追加尝试：清空空 tile

实现：

```cpp
MultiParticleContainer::PruneEmptyParticleTiles()
```

对每个 species/level，删除 `numParticles()==0` 的 tile。

结果：

```text
仍报 index 2 is out of bounds for axis 0 with size 2
```

说明旧 grid 对应的 tile 仍非空，或 `Redistribute` 未把其粒子搬到新 tile。
仅删除空 tile 不足。

该试验已回滚。

### 追加尝试：合并旧 tile

实现：

```cpp
WarpXParticleContainer::MergeStaleParticleTiles()
```

把 `grid_id >= ParticleBoxArray(lev).size()` 的 tile 粒子合并到有效 tile，
再 `Redistribute`。

结果：

```text
STEP 7
munmap_chunk(): invalid pointer
malloc(): unaligned tcache chunk detected
SIGABRT
```

出现内存破坏，说明直接对不同 tile 做 `resize + copyParticles` 不安全。
试验已回滚。
