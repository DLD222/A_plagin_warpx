## 二、物理公式清单（每条都要在代码里能被逐行核对）

### A. 引力
- 泊松方程：∇²φ = 4πGρ（弱场、非相对论、牛顿极限）
- 加速度：**g** = −∇φ；流体动量方程中的源项 ρ**g**
- 边界条件：开放边界用多极展开或 Dirichlet 在边界上的解析值；
  周期边界需减去平均密度（Jeans swindle）：∇²φ = 4πG(ρ − ρ̄)
- 参考解（验收用）：
  - 均匀球：内部 |g| = (4/3)πGρr，外部 GM/r²
  - 点质量势：φ = −GM/r
  - 双同心球壳
  - 等温球（King/Plummer）作为数值对照

### B. 五阶矩流体（Euler 型，无粘；可选粘性项留接口）
- 守恒形式：∂U/∂t + ∇·F = S
  - U = (ρ_s, ρ_s**u**_s, E_s)，E_s = ½ρ_s u_s² + (3/2)p_s（单原子理想气体）
- 通量：F = (ρ**u**, ρ**uu** + p I, (E + p)**u**)
- 源项：ρ**g**（引力）、组分反应、可选辐射冷却
- 多方/自定义 EOS：p = p(ρ, e, X_i) —— **物态方程通过契约注入**，不写死在求解器里
- Riemann 求解器：HLLC（Toro 2009, ch.10），二阶 MUSCL-Hancock + minmod
- 多组分：每种组分独立守恒（ρ_s 方程 + 反应源项），共享速度与温度（单流体多组分模型）

### C. 反应（太阳为主）
- pp 链：p + p → D + e⁺ + ν_e；D + p → ³He + γ；³He + ³He → ⁴He + 2p（及 ³He+⁴He → ⁷Be + γ 分支）
- CNO 循环：¹²C(p,γ)¹³N(β⁺ν)¹³C(p,γ)¹⁴N(p,γ)¹⁵O(β⁺ν)¹⁵N(p,α)¹²C
- 反应率：取自 **NACRE II** 或 CF88 拟合式（表单化，注明出处与温度适用范围）
- 能量产生率 ε(ρ, T, X_i) 与中微子损失分开记录

### D. 数值守恒与稳定性检查
- 总质量、总动量、总能量（含引力势能）在无源情形守恒到机器精度
- 引力能：E_grav = ½∫ρφ dV（离散后应与解析球一致）

## 五、验收标准（每项都要有命令与输出）

1. **不影响其它插件**：`check_{core_purity,plugin_boundaries,kernel_coupling,build_boundaries}.py` 全 0/OK；
   既有套件失败集不变（2D 232/232、四维 570/573 等）。
2. **引力解析解**：均匀球内外的 |g| 与解析值相对误差 < 1e-3（网格加密收敛阶 ≥1.8）。
3. **流体基准**：Sod 激波与精确 Riemann 解对比（L1 误差随网格二阶收敛）；Jeans 不稳定性的临界波长与解析一致（±5%）。
4. **守恒**：无源情形质量/动量/能量守恒到 1e-12 相对误差。
5. **太阳**：与 SSM 对比 —— 中心温度 15.7 MK ±3%、中心密度 150 g/cm³ ±10%、光度 3.828e26 W ±2%、
   表面 Z/X 与所选 AGSS09 一致；给出逐层对比表与图。
6. **可复现**：一条命令跑完上述全部检查，输出表格。
