# A7.3 FieldSolver 细化与审计

> A7.1 已完成：Core 不 include WarpX.H，插件边界检查通过。
> A7.2 进行中：Diagnostics/IO 已拆插件。
> A7.3 目标：把场求解器做成**独立功能插件**，内部按物理功能模块化。
> A7 阶段**不删除 WarpX**；WarpX 继续作为 PicEm 的并行实现内核。

## 1. 当前真实状态

```text

  FiniteDifference/   (EvolveE/B + PML + macroscopic + hybrid)
  Electrostatic/
```

```text

单位契约未成立
```

## 2. 是否符合两个根本要求

### 插件化

不满足：

```text
FieldSolver 不是插件
PicEm 直接 include FieldSolver 头
FieldSolver 直接调用 WarpX 单例
```

### 模块化

部分满足：

```text
FiniteDifference / Electrostatic / PSATD / Implicit / Magnetostatic
已经按功能分目录
```

不满足：

```text
一个 Unit 仍跨多个算法
EvolveE/B 不是按算法单元
没有字段读写声明
没有禁用/替换测试
```

## 7. 风险

```text
EvolveE/B 模板与多算法耦合
PML/边界与 FieldSolver 状态共享
PSATD 依赖 FFT/FFT 后端
Implicit 依赖粒子质量矩阵
Hybrid 依赖粒子/流体状态
```

处理原则：

```text
先接口后迁移
每步保持可编译
每步 4D 回归
禁止用目录移动冒充完成
```
